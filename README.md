# Personal Portfolio — K Vishnu Vardhan Rao

A responsive, static portfolio made with HTML, CSS and JavaScript. No installation or build step required.

## Preview locally
Open `index.html` in your browser.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository named `portfolio`.
2. Select **Add file → Upload files** and upload `index.html`, `style.css`, and `script.js` to the root of the repository. Commit the changes.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. After GitHub Pages finishes deploying, the site will be at `https://YOUR-USERNAME.github.io/portfolio/`.

## Edit your details
Update text and links in `index.html`, colours and layout in `style.css`.
